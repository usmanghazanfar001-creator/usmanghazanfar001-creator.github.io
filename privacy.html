Privacy Policy

YT Comment Helper · Last updated: October 22, 2026

YT Comment Helper ("the app") is a personal tool, used only by its developer, to manage comments on the developer's own YouTube channel. This policy explains what data the app accesses and how it is handled.

Data the app accesses

With the developer's permission through Google OAuth, the app uses the YouTube Data API to access:

  • The developer's YouTube channel ID.
  • Comments left on the developer's own videos (comment text, the commenter's public display name, and the video title).

The app also posts replies to comments on the developer's own channel when the developer has approved them or has enabled automatic replies.

How the data is used

Comment text is used only to draft a reply. For this, the text of the comment, the commenter's public display name and the video title are sent to Groq (groq.com), a third-party AI service, which generates the draft. The data is not used for advertising, profiling or any other purpose.

Storage

The app runs on the developer's own computer. It stores an access token and a list of already-answered comment IDs in local files on that computer. The app does not operate a server or a database, and it does not store user data online.

Sharing

Data is not sold, rented or shared with anyone, except for sending comment text to Groq as described above to generate reply drafts.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token and state files from the computer removes all data the app has stored.
